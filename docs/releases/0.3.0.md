Первый оформленный релиз **Frixit Control Center**, объединяющий личный Python ControlCenter и UCC Revorked.

- Трёхрежимные политики AC / USB-C / Battery для CPU, устройств и служб; ручные режимы и запросы приложений.
- Калиброванная клавиатура: Enter 56, левый Shift 21, левый Ctrl 0; приоритет импортированных цветов/настроек.
- Native Lightbar и пять анимаций. Flash остаётся выключенным после Save, запуска и смены питания.
- Самостоятельный трей, батарея в ваттах, пользовательские NVIDIA-процессы с подтверждением завершения.
- Активация окна и переход на рабочий стол по клику в трее KDE Wayland.
- Уведомления об ошибках драйверов при входе и красная плашка Overview.
- Linux 7.3: исходный патч для custom TUXEDO DKMS/ITE Lightbar и описание восстановления.
- Общий sleep hook, action-only предложения частоты экрана KDE, offline migration и откат первого перехода.
- Новые русская/английская документация, сравнение проектов и 22 актуальных снимка интерфейса.

**Скачать:** пакет `frixit-control-center-0.3.0-1-x86_64.pkg.tar.zst` предназначен для актуального Arch/CachyOS. Исходники и SHA256SUMS приложены отдельно. Личные настройки и драйверы ядра не включены. Установка пакета сама не включает/запускает службу: порядок установки и перехода со старого контроллера описан в [руководстве](https://github.com/Frixlt/UCC/blob/v0.3.0/docs/BUILDING.md).

**Проверки:** CI собирает пакет и запускает изолированный CTest-набор, отдельные GUI-сценарии и тесты конвертера. Полный старый GUI-аудит ранее имел тайм-аут; весь GUI-набор не объявляется прошедшим. Настоящий аппаратный suspend/resume и другие ноутбуки ещё требуют проверки. Основная проверенная конфигурация: Mechrevo YAOSHI X6AR55xY / Core Ultra 9 275HX / RTX 5080 Laptop / KDE Wayland.

Старый Python CPU thermal/MSR-код и `gpu-run` исключены. Пресет кривых вентиляторов достигает 100% при 85 °C и не является лимитом температуры CPU.
